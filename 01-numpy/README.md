# NumPy Practice

This folder contains my hands-on practice with **NumPy**, a fundamental Python library for numerical computing and array-based data manipulation. These notebooks are part of my ongoing journey to learn data science through the CodeWithHarry Job Ready Data Science course.

## Topics Covered

- **Introduction to NumPy** — Creating arrays, understanding array properties, memory usage, and vectorization.
- **Array Creation** — Using `np.array()`, `np.zeros()`, `np.ones()`, `np.full()`, `np.eye()`, `np.arange()`, and `np.linspace()`.
- **Data Types** — Understanding array data types, type conversion, memory usage, complex numbers, strings, and object arrays.
- **Indexing and Slicing** — Accessing elements, slicing arrays, copying arrays, fancy indexing, and Boolean filtering.
- **Multidimensional Arrays** — Working with 2D and 3D arrays, accessing elements, slicing across dimensions, and performing operations along axes.
- **Broadcasting and Vectorization** — Performing efficient element-wise operations, working with arrays of different shapes, and normalizing numerical data.
- **Built-in Functions** — Practising statistical and mathematical functions such as mean, median, standard deviation, variance, sum, product, percentiles, cumulative sums, logarithms, and exponentials.
- **Exercises** — Applying array creation, reshaping, data type conversion, and conditional filtering.
